# 知见封面指南

## 目录

- 默认路线与回退
- 图片封面
- HTML 封面
- 合集与验证

## 默认路线与回退

在 Codex 中创建新作品或合集时，创作简报确认后默认调用内置 ImageGen 生成图片封面，不再单独询问“图片还是 HTML”。简报需要说明视觉隐喻、禁用方向、是否含精确文字；合集还要列明合集级与作品级封面数量。用户确认简报即确认这些封面任务。优化现有作品时，只有确认的修改范围包含封面才执行此流程。

仅在以下情况生成 HTML 封面：

- 用户明确要求 HTML 或确定性排版。
- 当前环境没有可调用的 ImageGen 能力。
- ImageGen 调用失败。
- 初次图片未通过检查，进行一次针对性重试后仍不合格。

不要因为主题偏结构、流程或数据就跳过 ImageGen；先用清晰视觉隐喻生成默认图片。回退时不要求用户配置 API Key，也不需要再次等待确认。

## 图片封面

### 调用与保存

1. 使用 Codex 提供的内置 ImageGen 能力，不硬编码模型名称或 API 参数。
2. 等作品标题、核心隐喻和视觉方向稳定后再生图，避免成品与内容脱节。
3. 检查初次结果；若文字、构图或主题明显错误，最多进行一次针对性重试，随后回退 HTML。
4. 将最终结果复制到当前作品的 `cover/` 目录，使用稳定文件名：`cover.png`、`cover.jpg` 或 `cover.webp`。
5. 新建包直接写入最终封面；优化已有包时不覆盖原封面，除非简报已授权更新。

### 构图规范

- 横向 16:10，目标展示视口 1200×750。
- 重要主体放在中央 80% 安全区，四周保留裁切空间。
- 延续知见的自然、温暖、克制和编辑感；根据主题使用苔绿、赭石、大地色或低饱和扩展色。
- 避免通用 AI 光效、霓虹科技背景、无意义粒子、品牌 logo 和水印。
- 默认不生成标题文字，因为作品卡片会在封面下方显示标题。
- 用户要求文字时，将文字逐字写入提示并在输出后检查；任何错字都必须重新生成或改走 HTML 封面。

### 提示词骨架

```text
用途：知见知识可视化作品封面
主题：<主题>
核心隐喻：<一个清晰的视觉隐喻>
构图：16:10 横向，主体位于中央安全区，四周保留裁切空间
风格：<写实/插画/科学教育/编辑设计>
色彩：自然、温暖、低饱和，与知见大地色语言协调
约束：无 logo、无水印、无界面截图、默认无文字、避免廉价霓虹和杂乱元素
```

### 文件验证

- 格式为 PNG、JPEG 或 WebP。
- 文件不超过 5MB。
- 最长边不超过 4096px。
- 预览为 16:10 时主体和关键信息不被裁切。
- 画面没有错误文字、畸形结构、无关符号或水印。

## HTML 封面

生成完整、自包含、固定 1200×750 设计视口的 HTML 文档。不得加载外部资源，不依赖脚本即可显示。

| 风格 | 内容特征 |
|---|---|
| 文雅纸本 `classic` | 人文、历史、通识、传统文化 |
| 结构网格 `structured` | 系统架构、模块关系、工程知识 |
| 清透留白 `minimal` | 核心概念、审美、轻量入门 |
| 杂志头版 `editorial` | 强观点、趋势、主题策展 |
| 数据大字报 `data` | 金融、统计、指标、数据分析 |
| 流程蓝图 `flow` | 流程、算法、因果链和路径 |

HTML 封面至少包含：准确标题、短眉题、短副标题、3–5 个关键词和与主题匹配的抽象图形。转义所有动态文本；标题分行后连接必须与原标题完全一致。

## 合集与验证

- 合集需要一套独立的合集级封面，用一个总体视觉隐喻表达学习路径或主题关系，不把任一子作品封面直接当合集封面。
- Codex 默认对合集级和每个作品级封面分别调用 ImageGen；单个失败时只回退该封面，不废弃其他合格图片。
- 合集中每个作品使用独立画面，不复制同一张图只改标题。
- 系列可以共享构图系统，但用编号、主题色或核心图形区分章节。
- 合集图片封面与作品图片封面均使用 PNG/JPEG/WebP；合集包不生成 GIF 封面。
- 每个作品包只保留简报确认范围内生成的最终一套封面。
- 在交付中分别报告合集封面及每个作品封面的类型、保存路径和验证结果。
