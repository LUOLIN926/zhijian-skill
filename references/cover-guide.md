## 选择封面路线

先根据内容给出推荐，再让用户确认。

| 路线 | 适合 | 不适合 |
|---|---|---|
| ImageGen 图片 | 抽象概念、自然科学、历史情境、具象物体、氛围叙事 | 需要绝对准确文字、密集数据或可重复排版 |
| HTML 封面 | 标题驱动、结构关系、流程、数据主题、系列统一 | 需要写实场景或复杂插画 |

ImageGen 不可用、失败或用户要求确定性输出时，直接使用 HTML 封面，不要求用户配置 API Key。

## 图片封面

### Codex ImageGen 工作流

1. 默认使用 Codex 内置 `imagegen` 能力，不硬编码模型、API Key、质量或输出路径参数；只有用户明确要求 CLI/API 路线时才切换。
2. 新建封面直接生成；编辑本地封面时，先用 `view_image` 检查目标，再把该文件作为编辑目标传给 ImageGen，并在提示中列出必须保留与必须改变的内容。
3. 内置 ImageGen 默认把结果保存在 `$CODEX_HOME/generated_images/`。生成完成后读取实际保存路径，再复制或裁切到作品包的 `cover/`；不要假设工具支持项目目标路径参数。
4. 迭代时保留当前封面，把候选图保存为版本化文件。用户明确确认替换后，才写入稳定文件名 `cover.png`、`cover.jpg` 或 `cover.webp`。
5. ImageGen 未必严格返回 16:10。先检查画面，再从安全区居中裁切，不拉伸；裁切后重新检查文字、主体和边缘。
6. 最终作品包只保留一套封面。替换图片封面时移除包内旧 `cover.html` 或其他候选图；旧版本如需保留，应移到作品包之外。

### 文字与信息层级

- 单作品卡片下方已有标题时，图片默认不重复标题。
- 合集封面默认包含准确的合集名称；可再包含一个短眉题和一个短副标题，最多三段文字，避免把章节列表或密集标签塞进图片。
- 用户要求文字时，在提示中使用 `Text (verbatim)` 逐段引用，只允许出现这些文字，并明确字体层级、分行规则和“不得添加其他字符”。
- 生成后逐字检查中文、英文、标点和空格；任何错字、缺字、重字、伪中文或额外文字都不能交付。先做一次只修文字的定向编辑，仍不正确则重新生成或征得用户同意改用 HTML 封面。
- 文字必须位于中央 80% 安全区，并在缩略图尺寸下仍清晰；不要把重要文字放在裁切边缘或复杂图形上。

### 构图规范

- 横向 16:10，目标展示视口 1200×750。
- 重要主体放在中央 80% 安全区，四周保留裁切空间。
- 延续知见的自然、温暖、克制和编辑感；根据主题使用苔绿、赭石、大地色或低饱和扩展色。
- 避免通用 AI 光效、霓虹科技背景、无意义粒子、品牌 logo 和水印。
- 默认不生成标题文字，因为作品卡片会在封面下方显示标题。
- 用户要求文字时，将文字逐字写入提示并在输出后检查；任何错字都必须重新生成或改走 HTML 封面。

### 提示词骨架

```text
用途：知见知识可视化作品封面
主题：<主题>
核心隐喻：<一个清晰的视觉隐喻>
构图：16:10 横向，主体位于中央安全区，四周保留裁切空间
风格：<写实/插画/科学教育/编辑设计>
色彩：自然、温暖、低饱和，与知见大地色语言协调
Text (verbatim)：<无文字；或逐段列出已确认的标题、眉题和副标题>
约束：只出现已确认文字；无 logo、无水印、无界面截图；避免廉价霓虹和杂乱元素
```

### 文件验证

- 格式为 PNG、JPEG 或 WebP。
- 文件不超过 5MB。
- 最长边不超过 4096px。
- 像素比例为 16:10；不得通过非等比拉伸获得。
- 预览为 16:10 时主体和关键信息不被裁切。
- 逐字核对所有指定文字，且画面没有额外文字、畸形结构、无关符号或水印。
- 作品包内只有一个最终封面，平台包导入检查能识别其类型。

## HTML 封面

生成完整、自包含、固定 1200×750 设计视口的 HTML 文档。不得加载外部资源，不依赖脚本即可显示。

| 风格 | 内容特征 |
|---|---|
| 文雅纸本 `classic` | 人文、历史、通识、传统文化 |
| 结构网格 `structured` | 系统架构、模块关系、工程知识 |
| 清透留白 `minimal` | 核心概念、审美、轻量入门 |
| 杂志头版 `editorial` | 强观点、趋势、主题策展 |
| 数据大字报 `data` | 金融、统计、指标、数据分析 |
| 流程蓝图 `flow` | 流程、算法、因果链和路径 |

HTML 封面至少包含：准确标题、短眉题、短副标题、3–5 个关键词和与主题匹配的抽象图形。转义所有动态文本；标题分行后连接必须与原标题完全一致。

## 合集与验证

- 合集中每个作品独立选择封面，不复制同一张图只改标题。
- 系列可以共享构图系统，但用编号、主题色或核心图形区分章节。
- 每个作品包只保留最终确认的一套封面。
- 在交付中报告封面类型、保存路径和验证结果。
