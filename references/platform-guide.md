# 知见平台指南

## 目录

- 作品形态
- 创建与发布
- 状态和审核
- 合集与封面
- 沙箱边界
- 导入导出

## 作品形态

| 类型 | 平台展示 | 适合 |
|---|---|---|
| 交互演示 | 固定 1280×720 设计视口缩放展示 | 动画、模拟、数据关系、单屏实验 |
| 动态书 | 响应式滚动 HTML 页面 | 教程、章节叙事、学习路径、内嵌演示 |

平台会把旧类型标签归并为以上两类。发布时 `tags[0]` 必须是当前类型标签。

动态书通过 `<section data-zhijian-chapter id="...">` 暴露有序章节，第一个 `h2` 作为章节标题。平台在作品 iframe 外生成统一目录，因此正文不应再包含章节导航；旧 `.chapter[id]`、章节导航锚点和 `h2` 仅作为历史作品的兼容回退。

## 创建与发布

1. 在 `/create` 直接选择 Skill 生成的完整作品或合集文件夹，或选择作品类型使用兼容的分文件上传。
2. 直接上传会自动解析 HTML、元数据、说明、封面和合集章节结构。
3. 在发布页确认标题、简介、使用说明、标签和合集。
4. 可使用平台 AI 填写元数据；HTML 封面支持智能推荐和六种可重排风格。
5. 普通用户提交后进入审核；具备直接发布权限的账户按平台角色规则处理。

单作品包导入 `schema_version`、`title`、`brief_description`、`usage_markdown` 和 `tags`。合集包还导入名称、短简介、Markdown 完整介绍、标签、章节树、全部子作品及合集/作品封面。

## 状态和审核

| 状态 | 含义 | 可见性 |
|---|---|---|
| `draft` | 草稿 | 作者 |
| `pending_review` | 新作品或更新内容待审核 | 作者和管理员；已有公开版本继续可见 |
| `published` | 已发布 | 所有人 |
| `locked` | 管理员锁定 | 按管理员规则 |
| `hidden` | 已隐藏/删除 | 不公开 |

已发布作品的修改会形成待审核版本，而不是立即替换公开快照。审核通过后新版本才成为公开内容；拒绝不应破坏上一个公开版本。

## 合集与封面

合集用于组织有先后关系的多个作品，支持章节层级、排序、合集资料和独立封面。每个作品仍应能被单独理解和运行。

完整合集包确认一次后原子创建合集、最多三级章节和全部作品；所有新作品统一进入审核，任何一个作品失败都不会留下半个合集。合集公开页只展示审核通过的作品。

平台封面支持：

- 上传 PNG/JPEG/WebP 等图片；当前上传限制为 5MB、最长边 4096px。
- 生成 HTML 封面：智能推荐或文雅纸本、结构网格、清透留白、杂志头版、数据大字报、流程蓝图。
- 已生成的结构化 HTML 封面可切换风格而不重新分析内容。

## 沙箱边界

作品在无 `allow-same-origin` 的 iframe 中运行，允许脚本和模态提示，但与平台页面隔离。

不要依赖：

- Cookie、localStorage、IndexedDB 或平台登录态
- 访问 `window.parent`、父页面 DOM 或父页面 CSS 变量
- 顶层导航、表单提交、弹出新窗口
- 需要密钥、私有请求头或受保护网络的 API

可以使用公开图片、字体、媒体、CORS API 和公共 CDN，但关键体验优先内联。为网络失败提供清晰回退，不把外部请求作为理解作品的唯一途径。

完整 HTML、HTML 片段和 React 片段都能在编辑器中预览，但作品包应交付完整 HTML 文档。

## 导入导出

平台下载包包含源码、元数据、使用说明以及现有图片或 HTML 封面。只有作品创作者可以下载自己的可下载作品。

重新上传或直接上传时：

- 平台 ID、状态和时间戳不会沿用。
- `work.json` 和 `collection.json` 用于预填资料；清单里的平台封面路径不会沿用，实际封面来自包内 `cover/`。
- 选择整个根目录即可自动读取文件；不支持 ZIP，也不把多个散装作品的上级目录自动猜成合集。
