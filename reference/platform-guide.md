# 知见平台使用指南

## 编辑器界面

### 分栏视图

编辑器采用左右分栏布局：
- **左栏**：代码编辑区
- **右栏**：实时预览区。交互演示按固定动态演示 window 预览，动态书按可滚动网页预览。

代码修改后预览区会自动更新，无需手动刷新。

### 代码模式

支持两种编辑模式：

| 模式 | 说明 | 适合 |
|------|------|------|
| 分栏模式 | HTML、CSS、JavaScript 分离为三个标签页 | 结构清晰、便于维护 |
| 整合模式 | 单个 HTML 文件包含所有代码 | 快速原型、简单作品 |

可通过工具栏切换模式。

### 工具栏功能

| 按钮 | 功能 |
|------|------|
| 保存草稿 | 保存当前代码到草稿 |
| 版本历史 | 查看和恢复历史版本 |
| 提交发布 | 进入发布流程 |
| 预览设置 | 调整预览区尺寸 |

## 创建作品流程

### Step 1 · 选择作品类型

访问 `/create`，先选择作品类型：

| 类型 | 展示方式 | 适合 |
|------|----------|------|
| 交互演示 | 固定 16:9 动态演示 window | 数据可视化、动画模拟、单屏交互实验 |
| 动态书 | 上下滚动的 HTML 阅读页面 | 长文教程、章节叙事、流程路径、内嵌动态演示 |

现有旧类型（互动图片视频、流程图）会被平台归并为交互演示。

### Step 2 · 打开编辑器

选择"在线编辑"进入 `/editor` 路径。
- 未登录用户会被引导至登录页
- 管理员账户会被引导至管理后台

### Step 3 · 编写代码

在代码区编写 HTML/CSS/JavaScript：
- 支持语法高亮
- 支持代码自动补全
- 预览区实时显示效果

### Step 4 · 预览验证

实时查看预览区效果：
- 检查布局是否正确
- 检查交互是否正常
- 检查响应式是否适配
- 动态书需要检查页面滚动、章节衔接和内嵌演示

### Step 5 · 保存草稿

点击"保存草稿"按钮：
- 作品保存为 draft 状态
- 仅自己可见
- 可随时继续编辑

## 发布流程

### Step 1 · 提交发布

从草稿页面点击"提交发布"按钮。

### Step 2 · 填写信息

| 字段 | 说明 | 是否必填 |
|------|------|----------|
| 标题 | 作品标题 | 必填 |
| 简介 | 简短描述（最多 100 字） | 必填 |
| 作品类型 | 交互演示 / 动态书 | 必填 |
| 使用说明 | Markdown 格式的详细说明 | 可选 |
| 标签 | 最多 5 个标签 | 必填至少 1 个 |
| 合集 | 所属合集 | 可选 |

### Step 3 · AI 辅助（可选）

点击 AI 辅助按钮可自动生成：
- 作品标题（基于 HTML 内容分析）
- 作品简介
- 使用说明

AI 生成的内容可手动修改。

### Step 4 · 封面图片

两种方式设置封面：

| 方式 | 说明 |
|------|------|
| 上传图片 | 从本地选择图片文件 |
| HTML 生成 | 从作品 HTML 自动生成截图 |

封面图片会在探索页面展示。

### Step 5 · 提交审核

填写完成后点击"提交审核"：
- 作品进入 pending_review 状态
- 等待管理员审核
- 审核通过后变为 published 状态

---

## 作品状态说明

| 状态 | 说明 | 可见范围 |
|------|------|----------|
| draft | 荧稿 | 仅作者 |
| pending_review | 待审核 | 仅作者和管理员 |
| published | 已发布 | 所有人 |
| locked | 已锁定 | 仅管理员 |

## 合集功能

### 什么是合集

合集是将多个相关作品组织在一起的容器：
- 适合系列教程、主题作品集
- 合集内的作品按章节顺序排列
- 合集有自己的封面和介绍

### 创建合集

1. 从个人页面点击"创建合集"
2. 填写合集名称和介绍
3. 选择要包含的作品
4. 设置作品顺序

### 合集页面

合集页面显示：
- 合集封面和介绍
- 作品列表（按章节顺序）
- 当前作品高亮
- 上一章/下一章导航

## 探索页面

### 发现作品

访问 `/explore` 浏览已发布作品：
- 作品卡片展示封面、标题、简介
- 点击卡片进入作品详情页

### 搜索功能

在搜索框输入关键词：
- 搜索标题、简介、标签
- 支持中文和英文

### 排序方式

| 排序 | 说明 |
|------|------|
| 最新发布 | 按发布时间倒序 |
| 最受欢迎 | 按点赞数倒序 |
| 最多浏览 | 按浏览量倒序 |

### 分页

页面底部有分页导航：
- 每页显示固定数量作品
- 点击页码切换页面

## 个人页面

### 我的作品

访问 `/works/manage` 管理自己的作品：
- 查看所有草稿和已发布作品
- 编辑草稿
- 删除作品
- 查看作品状态
- 下载作品包（ZIP 格式，包含源码、元数据和封面）

### 下载作品包

每个作品卡片上有"下载作品包"按钮，点击后下载 ZIP 压缩包：

- 仅作品创作者可下载，管理员不可下载他人作品包
- 隐藏状态的作品不可下载
- 文件名格式：`{作品标题}-{ID}.zip`

作品包包含：
- `source/index.html` — 作品 HTML 源码
- `metadata/work.json` — 结构化元数据（标题、简介、标签等）
- `metadata/usage.md` — 使用说明
- `cover/` — 封面文件（图片或 HTML）

用途：备份、离线编辑、版本存档。编辑后可通过 `/create` 页面的"上传作品"功能逐文件重新上传。

### 收藏夹

访问 `/bookmarks` 查看收藏的作品：
- 创建收藏夹分类
- 将作品添加到收藏夹
- 从收藏夹移除作品

### 个人主页

访问 `/user/:id` 查看用户主页：
- 用户头像和简介
- 用户发布的作品列表
- 用户创建的合集

## 安全沙箱说明

### 什么是沙箱

所有作品在隔离的 iframe 中运行：
- 与主页面完全分离
- 无法访问用户的敏感数据
- 无法影响其他页面

### 安全限制

作品代码无法：
- 访问用户 Cookie
- 访问本地存储
- 发起跨域请求（受 CORS 限制）
- 执行恶意操作

### 用户保障

即使是包含复杂脚本的作品：
- 也可以放心查看
- 不会影响浏览器安全
- 不会泄露个人信息
