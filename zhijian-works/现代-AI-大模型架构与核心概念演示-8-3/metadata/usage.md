## 简介
此交互式演示通过可视化的方式展示现代 AI 大模型架构与核心概念，从用户输入到工具调用的完整生命周期。你可以通过点击按钮逐步浏览每个环节，观察节点高亮、连线动画和详细的文字解说。

## 使用方法
1. 打开页面后，你将看到主演示区域和底部的控制面板。
2. 点击「开始演示」或「下一步」按钮，从第一步"初始输入"开始。
3. 每点击一次「下一步」，演示会前进到下一个步骤，包括对应的节点高亮、连线激活和粒子动画，同时右侧面板会显示该步骤的标题和详细解释。
4. 你可以随时点击「上一步」按钮回退到之前查看过的步骤，重复理解。
5. 底部的进度点会标记你已完成的步骤。

## 注意事项
- 请确保您的浏览器支持 CSS3 和 Web Animations API，以获得最佳观看体验。
- 建议在宽屏设备上查看，以获得完整的布局和动画效果。
- 演示中的动画和文字说明是预设的，请按顺序操作以理解完整流程。
- 页面中显示的 Token 数量和上下文窗口变化是示例性的，并非真实运行的大模型反馈。
