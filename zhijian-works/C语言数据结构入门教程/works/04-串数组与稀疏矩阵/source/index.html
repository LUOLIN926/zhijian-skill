01 · 核心概念

C 字符串不是神秘类型

字符串是以 '\0' 结尾的 char 数组。strlen 不计终止符，缓冲区却必须为它留位置。

边界与选择

读取和拼接前先确认容量；缺少终止符会让函数继续越界寻找。

02 · 核心概念

二维数组仍是连续内存

C 按行优先存储二维数组。a[i][j] 的线性偏移为 i×列数+j。

边界与选择

把二维数组传给函数时，编译器需要知道除第一维以外的维度。

03 · 核心概念

朴素模式匹配

从每个可能起点比较模式串；失败时文本起点向右移动。最坏情况下需要 O(nm) 次比较。

边界与选择

KMP 是选学拓展；主线先保证理解下标、边界和匹配失败。

04 · 核心概念

稀疏矩阵只存非零项

当大多数元素为 0 时，可记录每个非零项的行、列和值，显著节省空间。

边界与选择

压缩结构适合稀疏数据；若非零项很多，额外索引反而可能更贵。
