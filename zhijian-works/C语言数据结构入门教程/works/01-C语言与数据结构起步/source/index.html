01 · 核心概念

程序从哪里开始

C 程序由函数组成，main 是入口。变量有类型，表达式产生值，控制流决定执行顺序。

边界与选择

把编译错误看成反馈：先读第一条错误，再检查分号、类型和作用域。

02 · 核心概念

数组与指针

数组是一段连续、同类型的内存；指针保存地址。a[i] 等价于 *(a+i)，但数组和指针并不是同一个概念。

边界与选择

下标从 0 开始；越界访问属于未定义行为，程序不会自动替你检查。

03 · 核心概念

结构体与动态内存

结构体把相关字段组织成一个值；malloc 在堆上申请字节，成功后返回地址，使用完必须 free。

边界与选择

每次 malloc 都要检查 NULL，并明确所有权：谁申请，谁释放。

04 · 核心概念

ADT 与复杂度

抽象数据类型先规定操作与语义，再选择存储实现。大 O 描述输入规模增长时的主要增长级别。

边界与选择

同一 ADT 可有多种实现；比较时同时考虑时间、空间和使用场景。
