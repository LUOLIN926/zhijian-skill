# MACD 指标入门 - 使用说明

## 作品简介

本作品是一个交互式 MACD 技术指标学习工具，帮助用户从零开始理解 MACD 的概念、组成、计算原理和信号解读。

## 学习路径

作品分为四个章节，建议按顺序学习：

### 章节 1：概念
了解 MACD 的基本定义、作用和应用场景。

### 章节 2：组成
学习 DIF（快线）、DEA（慢线）、MACD柱的含义。
- 点击右侧切换按钮，隐藏/显示各条线，观察其特征
- 理解每条线反映的趋势信息

### 章节 3：计算
深入了解 MACD 的计算过程。
- **参数调节**：拖动滑块调整快线周期、慢线周期、DEA周期，实时观察变化
- **演示计算**：点击按钮观看逐步计算动画
- **模拟股价**：在上方图表区域拖拽绘制曲线，观察 MACD 的响应

### 章节 4：信号
学习买卖信号的识别方法。
- **历史回放**：点击播放按钮，观看走势演变和信号生成过程
- **信号标注**：图表上自动标注金叉/死叉/背离点，点击右侧解读面板查看详细说明
- **底背离**：股价创新低但 MACD 未创新低，预示反转上涨
- **顶背离**：股价创新高但 MACD 未创新高，预警反转下跌

## 交互操作

| 操作 | 说明 |
|------|------|
| 标签切换 | 点击顶部标签切换章节 |
| 参数滑块 | 拖动调节周期参数 |
| 拖拽绘制 | 在计算章节的图表区域绘制模拟股价 |
| 播放回放 | 在信号章节播放历史走势演变 |
| 点击标注 | 查看信号详细解读 |

## 技术说明

- 本作品使用纯 Canvas + 原生 JavaScript 实现，无外部依赖
- 数据为抽象示意数据，模拟一段完整的市场走势
- 参数默认值：快线周期 12、慢线周期 26、DEA周期 9

## 适用人群

- 股票投资入门者
- 技术分析学习者
- 金融知识爱好者

## 学习建议

1. 先完整阅读概念章节，建立基本认知
2. 在组成章节反复切换各线，理解其特征
3. 在计算章节尝试不同参数组合，观察 MACD 的敏感度变化
4. 在信号章节完整观看回放，理解信号的时间维度
5. 尝试拖拽绘制不同走势形态（上升、下跌、震荡），观察 MACD 响应
